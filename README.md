An Arduino-based Bluetooth-controlled car that can be operated wirelessly using a smartphone. The project uses an Arduino, Bluetooth module, and motor driver to control the movement of the car in different directions.
✨ Features
📱 Wireless control through Bluetooth
⬆️ Forward movement
⬇️ Backward movement
⬅️ Left and right turns
⏹️ Stop control
⚡ Arduino-based motor control
🛠️ Technologies & Components
Arduino
Bluetooth Module
Motor Driver
DC Motors
Robot Car Chassis
Battery
This project demonstrates wireless communication, Arduino programming, and basic robotics concepts.
